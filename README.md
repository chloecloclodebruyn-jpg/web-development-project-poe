# Web Development Learning Portfolio

A collection of beginner HTML and CSS exercises, a portfolio landing page, and a portfolio of evidence.

## View the work

Open `index.html` in a browser to browse the projects. Open `evidence.html` for a skill-by-skill index with links to the completed pages and downloadable source files. No build step or package installation is required.

The portfolio styles and font exercises request Google Fonts when online; the pages use local, original SVG artwork and remain usable if those fonts are unavailable.

## Use with GitHub Copilot

The `.github/copilot-instructions.md` file gives Copilot project-specific context and conventions. VS Code will recommend the GitHub Copilot and Copilot Chat extensions from `.vscode/extensions.json`. Open this folder, sign in to GitHub, and use Copilot Chat or inline suggestions as available in your account.

## Publish with GitHub Pages

The public repository contains the portfolio and 31 exercises, including a Flexbox pricing-table comparison of GitHub, GitHub Copilot, and Poe free plans. ZIP archives, PDFs, installer images, raster reference images, answer files, logs, and macOS metadata are excluded by `.gitignore`; the completed pages use original SVG illustrations instead. After the code is pushed, open **Settings → Pages**, choose the `main` branch and `/ (root)` as the publishing source, and save. Add any personal profile or contact details you want to share before publishing; none are required by the current pages.
